# 入力エラーの表示

2026-11-03追加。入力検証でエラーになったinput・select・textareaを赤枠と薄い赤の背景で表示し、欄の近くにエラー文を表示する。未入力の必須欄も、検証前は通常の色にする。
全画面でブラウザーの必須・形式・範囲・単位の検証を共通処理し、`aria-invalid` と `aria-describedby` を設定する。必須テキストの空白だけの入力も拒否する。修正して検証を通ると赤表示とエラー文を取り除く。入力途中の値は保持する。
イベント登録では、開催日の重複、単回で複数日、主な参加対象の未選択、懇親会の追加検証も該当欄・グループを赤くする。通信障害や保存競合は従来の全体エラーとして表示する。
PC・スマートフォンのブラウザーで、イベントの必須選択、空白だけのセミナー名、その他の懇親会参加者の氏名未入力、タスクテンプレートの必須名と、各修正後の色解除を確認する。

新規・編集フォームは項目別に開閉する。閉じた項目に入力エラーがある場合、その項目を開いて赤表示と説明を示す。
