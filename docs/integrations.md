# 外部連携の検証計画（全て未接続）

Google／LINE／Gmail／Dropboxの実API呼出し、送信、フォーム公開、カレンダー更新、招待は今回行わない。仕様書中の実データ参照URLやIDをテストコードへコピーしない。

| 接続 | 採用前の検証 | 予定する安全な境界 |
|---|---|---|
| Forms/Sheets | 個人Googleアカウントの所有・編集権限、OAuth同意／審査、必要scope、フォーム生成・公開・回答先設定の対応API、トリガー権限、同期遅延とquota | 架空フォームで生成プレビュー。入金管理列は質問から除外。原本行IDを保持して重複排除・定期照合 |
| 研究会Gmail | 個人Googleとは別の送信主体、送信認可・scope・上限・返信先、組織ポリシー | 宛先／件名／本文プレビューと明示承認、outboxと重複防止。既定で送信無効 |
| 共有Calendar | 共有カレンダーIDと編集権限、認可主体、日付・タイムゾーン | 開催日と重要タスクのみ一方向更新。外部予定IDを保持。取消ルールはU19 |
| LINE公式アカウント | グループ参加可否・招待条件、groupIdの取得、送信許諾、トークンとプラン／quota／料金 | 通知先を本番と分離。毎日08:00 JSTの内部ジョブを先にテスト。実送信は承認後 |
| Dropbox | 既存リンクのアクセス権と保管方針 | 初期はリンク参照。自動アップロードは採用しない |

資格情報はチャットで収集せず、採用後に安全な環境設定から投入する。OAuth接続主体・同意scope・有効期限・失効・再認可を記録し、ブラウザーにはトークンを返さない。テストと本番の鍵、カレンダー、送信先、DBを分離する。

再試行には冪等キー・外部リソースIDを用い、外部成功／内部保存失敗を試験する。失敗の最終状態はアプリ内に残し管理者2名へ通知する。回数・間隔・通知チャネルはU21として未決定。HP自動投稿、委託先LINE自動送信、銀行自動振込を追加しない。
