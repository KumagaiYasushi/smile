# 開催日の天気予報

HOME、イベント一覧（カード・行表示）、イベント詳細に、開催日の7日前から当日までの予報を表示します。日本時間の暦日で判定し、複数日開催は開催日ごとに表示します。開催後・日程未定・オンラインのみの日程は対象外です。現地開催とオンラインを併用する日程は対象です。

表示項目は天気、最高気温、最低気温、予報地域、気温の予報地点、発表日時です。晴れ・曇り・雨・雪などは気象庁の予報を使用し、「大雨」「暴風雨」等は赤い背景で目立たせます。これは天気予報の表示で、警報・避難情報の表示機能ではありません。出典は気象庁と明記し、気象庁の予報ページへリンクします。

## 会場の住所

イベントに保存されている「会場」の文字列から、都道府県と市区町村を判定します。例えば `架空会議室 / 東京都新宿区…` のように設定します。会場台帳から選択すると住所も会場欄へ転記されます。台帳の住所を後から更新した場合は、イベントで会場を選び直して反映します。判定できない住所や複数地域が混在する住所では、住所の設定を促します。

日本国内の気象庁の地域予報です。気温は気象庁が提供する代表地点の予報で、会場の建物の気温ではありません。予報地域と気温の予報地点を併記します。予報や気温が提供されていない場合は「未発表」と表示し、空欄を0℃として表示しません。

## 取得と更新

APIキー・サービス契約・追加の環境変数は不要です。気象庁の公開JSONをサーバーから取得し、地域情報を24時間、予報を1時間キャッシュします。1時間ごとに再確認し、開いたまま日本時間の日付が変わった場合も表示対象を更新します。取得失敗時は5分後に再確認し、イベント本体は表示を続けます。36時間を超えて古い発表データは表示しません。

`GET /api/weather` はログイン済みの運営メンバーのみ利用できます。応答は `Cache-Control: no-store` です。気象庁へ送るのは固定の公開URLと予報地域コードのみで、イベント名・会場住所・参加者情報は送信しません。サーバーは以下のエンドポイントへのHTTPS通信が必要です。

- `https://www.jma.go.jp/bosai/common/const/area.json`
- `https://www.jma.go.jp/bosai/forecast/data/forecast/{地域コード}.json`

外部通信のタイムアウト、応答容量、同時接続数を制限します。取得失敗・形式の変更・未発表の場合に、別の日や別の地域の天気を推測して表示しません。

## 確認方法と制限

`node --test tests/weather.test.mjs` で、7日前の境界、日本時間、地域判定、日別開催方法、気温欠損、予報の優先順位、キャッシュと取得失敗を検証します。

`npm run build` 後の `node scripts/check-weather.mjs` は、気象庁形式の模擬JSONを使い、実際のアプリAPIから画面までをPC（1280px）・スマートフォン（390px・320px）で確認します。実際の気象庁への通信は行いません。

開発環境のネットワーク制限により、実際の気象庁データへの接続確認は未完了です。公開環境で直近7日以内のイベントを登録し、会場住所に対応する予報地域・気温の予報地点・発表日時が表示されることを確認してください。気象庁の公開JSONの形式が変わった場合は追従が必要です。
