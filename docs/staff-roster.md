# イベントごとの名簿・ラジオボタンによる出欠登録

2026-11-02の追加要望。ベーシックコース・講演会・セミナーの各イベントで、研究会講師と研究会サポートメンバーの名簿を使って出欠を登録する。

新規登録・編集画面にも同じ名簿フォームを配置している。この場合はラジオの選択内容をイベントの保存ボタンでまとめて保存する。[登録画面の操作](event-registration-extras.md) を参照。

## 操作

1. イベント詳細の「講師・サポートの出欠予定」を開く。
2. 「研究会講師・サポートの出欠登録」で開催日を選ぶ。単回は1日、日程未定は「日程未定」を表示する。
3. 各氏名のラジオボタンで「出席」「午前のみ」「午後のみ」「欠席」「未登録」を選ぶ。選択すると保存する。

| 状態 | 氏名・行の表示 |
| --- | --- |
| 出席・午前のみ・午後のみ | 緑の文字と薄い緑の背景 |
| 欠席 | グレーの文字と背景 |
| 未登録 | 黒の文字と白の背景 |

欠席も入力を無効にせず、出席や未登録へ変更できる。色に加えて文字・選択状態で区別する。
複数回では開催日を切り替えて登録する。他の開催日や他イベントへ出欠を自動コピーしない。
名簿の全利用中メンバーを初めから表示するが、出欠の選択前にはイベントへ登録行を作らない。指定の講師6名・サポート4名は初めから未登録として選べる。

## 保存・既存データ

- 保存に成功した後で色と表示を更新する。保存中は出欠操作を止め、失敗時は保存済みの状態を残してエラーを表示する。
- 別の操作で出欠・名簿・開催日が変わった場合は上書きせず、最新情報の取得を案内する。
- すでに同じ区分・氏名の出欠予定がある場合は、その記録へ紐付けて回答を保持する。
- 名簿のIDとイベントの出欠IDを関連付ける。登録後に名簿を改名しても出欠を失わず、このイベントの氏名は登録時の記録を表示する。現在の名簿名が異なる場合は併記する。
- 名簿で利用停止した人は新しいイベントの候補から外す。すでに出欠のあるイベントでは引き続き確認・変更できる。
- 従来の「調整中」は未確定の黒で表示し、既存値を保持する。ラジオ選択で出席・欠席・未登録へ変更できる。
- 旧日程の予定、外来講師や旧区分の記録は従来の個別編集・履歴で確認できる。
- 日程変更後、新しい日付は未登録から確認する。旧日付の回答は保持し、同じ日付へ戻した場合は既存回答を使う。
- 参加者名簿の実出席や入金情報は変更しない。

## API・検証

GET `/api/seminars/{id}/staff-attendance` に `roster`（開催日、名簿行、保存済み回答、名簿・出欠のバージョン）を追加した。
POST `/api/seminars/{id}/staff-attendance/roster` へ `member_id`、`member_version`、`version`、`schedule`、`date`、`response` を送る。
`response` は `ATTENDING` / `ABSENT` / `UNANSWERED`。氏名や操作アカウントの直接指定は受け付けず、ログイン済み運営メンバーと同一Originを確認する。
出欠保存・名簿との関連付け・履歴は一つのトランザクションで保存し、途中の失敗時は全体を戻す。

単体テストは未登録表示、イベント・開催日の分離、旧回答、名簿変更、競合、保存失敗のロールバック、削除の関連付け解除を確認する。
API結合テストは全3種別で出欠登録・変更・別イベントの未登録状態・不正な更新の拒否を確認する。
PC・スマートフォンのブラウザーテストではラジオ選択、緑・グレー・黒の表示、欠席からの変更、日付切り替え、再表示、503時の表示保持と再保存を確認する。
