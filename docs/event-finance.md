# イベントの収支見積もり

2026-11-03追加。イベント詳細の「収支見積もり」から利用する。全4イベント種別で共通。ログイン中の運営メンバーが確認・編集できる。

## 自動計算

- 参加費収入は、未入金を含む申込人数×職種別の通常参加費。複数回コースでは合計参加費を使い、開催回数で再び掛けない。同じ申込者を各開催日に重複計上しない。
- 再受講・割引などは「参加費収入の調整」で補正する。追加収入はプラス、割引分はマイナス。確認済み入金額は収入へ加算せず参考表示する。
- 協賛費を入力し、参加費収入・調整額との小計を表示する。
- お車代・謝礼は外来講師ありのイベントから読み取り、会場費と昼食費を加える。外来講師なしで保持している過去の金額は支出へ含めない。従来の外来講師区分・氏名だけが登録されたイベントも外来講師ありとして扱う。
- 昼食費は中止以外の手配の個数×単価＋追加費用。未定の手配は未定件数を表示し、入力済みの小計だけを使う。
- その他支出を入力できる。収入小計−支出小計を差引見込みとする。懇親会の会計はこのイベント見積もりと分け、各懇親会の人数×参加費で確認する。

申込者の追加・職種変更・削除、イベントの料金・会場費・外来講師金額、昼食手配の編集後は、画面を開き直すか「最新の見積もりを取得」で再計算する。編集中の設定は破棄確認を行う。
空欄は未定、0は0円。未定の項目は明示し、小計に入力済みの金額だけを含める。協賛費・その他支出・調整・メモは保存後に計算へ反映する。実際の送金や請求は行わない。

## 保存・API

GET `/api/seminars/{id}/finance` は `settings`、`version`、`estimate`。PATCHは取得済み `version`（初回0）と編集する設定を送り、未送信項目は保持する。
設定は `sponsorship`、`participation_adjustment`、`other_expenses`、`notes`。金額は安全な整数、調整以外は0以上またはnull、メモは2000文字以内。合計計算はBigIntを使い、APIの集計金額は文字列で返す。
`event_finance` にイベントID、設定JSON、版、操作アカウント、更新日時を保存する。既存イベントは未設定から始める。更新は同一トランザクションで、競合は409。無効アカウント、不正値、別Origin、未認証は拒否する。イベント削除時は関連設定も削除する。収支やメモは公開用開催要項PDF・SNSへ掲載しない。

単体・APIで未入金申込を含む職種別集計、金額調整、協賛費、昼食・外来講師費・会場費、申込変更後の再計算、未定・0円・大きな金額、不正値・競合・イベント範囲・CSRFを確認する。ブラウザーでは3画面幅で設定保存、申込変更後の再取得、金額表示を操作する。
