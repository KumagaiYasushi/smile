# メール・カレンダー自動化設定

HOME → システム設定 → メール・カレンダー自動化設定 (`/settings/automation`) で以下を一画面に集める。

- メール接続：ログイン中のアカウントのGmail接続・解除・初回手順。
- カレンダー接続・同期：研究会の共有カレンダーの接続・解除・未同期の再処理・状況確認。接続・解除は従来どおり管理者のみ。
- イベントごとの自動メール：対象を選び、既存の参加者名簿と同じ設定パネルを使う。共通2口座、イベント別振込先、任意の臨床相談URL、ベーシックだけの課題、Googleフォーム用スクリプト、自動送信の有効化、送信状況を扱う。イベント選択だけでは有効にしない。
- 自動化の動作一覧とメール送信履歴へのリンク。

GmailとカレンダーのGoogle許可はそれぞれ取得する。接続設定を共通画面へ集めても、既存の権限・送信元の制限・自動送信条件は変更しない。旧 `/gmail`、`/calendar`、参加者名簿での設定も維持する。

統合画面からのGoogle接続では、完了後の戻り先を統合画面にする。戻り先は `automation` という固定フラグだけをCookieに保持し、任意URLは受け付けない。既存のOAuthの状態・PKCEと認証は保持し、Cookieはコールバックで破棄する。

イベントを切り替える際、未保存の入力または表示中のフォーム連携スクリプトがあれば確認する。保存処理中はイベント選択を無効にし、別イベントへ誤って保存する操作を防ぐ。設定ページへ戻る時やブラウザを閉じる時も未保存の内容を確認する。

確認：`scripts/check-automation-settings.mjs` でPC・スマートフォンの一画面表示、イベント別保存、未保存切り替え防止、Googleコールバックの固定戻り先、管理者制限と従来画面を確認。模擬申込のみを使い、Googleへメール・予定を送信しない。
