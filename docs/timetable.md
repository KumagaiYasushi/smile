# タイムスケジュール

各イベントのメニューから「タイムスケジュール」を開く。開催日が複数ある場合は日程ごとに作成でき、日程未定でも検討を始められる。

「開会の挨拶」「挨拶」「休憩」「昼休憩」「講演」「ディスカッション」「グループディスカッション」「閉会の挨拶」「協賛CM」と、イベントに登録した各演者の講演を複数選択して追加する。選択肢ごとの所要時間を分単位で指定でき、追加後も項目名と所要時間を編集できる。同じ休憩・挨拶・講演は何度でも追加可能。

開始時刻と所要時間から各項目の開始・終了時刻と全体の終了時刻・合計時間を自動計算する。上下ボタンまたはドラッグで順序を変更すると、その場で時刻を再計算する。保存すると全日程の予定が保存される。終了が翌日になる予定は開始時刻または所要時間を調整してから保存する。

未保存の変更は画面に表示し、再取得時は破棄を確認する。別の利用者が保存した場合は競合エラーを表示し、編集中の内容を保持する。

開催日や演者が変更された場合も保存済みの予定は自動削除しない。旧日程には「旧日程」を表示し、新しい開催日には空の予定を用意する。削除した演者の既存講演は氏名・テーマの記録を保持し、新たな選択肢には現在の登録演者だけを表示する。

APIは `GET /api/seminars/:id/timetable`、`PUT /api/seminars/:id/timetable`。運営メンバーのログインと書き込み時の同一Origin検証が必要。バージョン管理により同時編集の上書きを防ぐ。外部講師への支払い情報は返さない。

## 時間枠・編集・ドラッグ

基本情報に登録した開催日の開始・終了時刻を「基本情報の講演時間」に表示し、時間枠とスケジュール終了までの残り時間・超過分を確認できる。「基本情報の開始時刻に合わせる」で開始時刻を揃えられる。時間枠は検討の目安として表示し、超過した案も保存して調整を続けられる。時刻未設定の日程は未設定と表示する。

所要時間は入力途中に空欄にできる。空欄のまま保存はできず、所要時間が未入力の間は時刻を「—」で表示する。項目名は「項目名（編集可）」で変更し、保存後も保持する。

移動は各項目の「つかんで移動」ハンドルを使う。PCはマウス、スマートフォンは指でドラッグでき、移動先を枠線で表示する。名前や所要時間の入力欄はドラッグの開始対象にしない。上下ボタンも利用できる。

昼休憩の初期所要時間は60分、ディスカッション・グループディスカッションは30分。各項目の所要時間は自由に変更できる。

## 追加する個数

「追加する項目」で項目を選び、「追加する数」と「1項目の所要時間（分）」を入力してから追加する。昼休憩、ディスカッション、グループディスカッション、登録演者の講演を含むすべての選択肢で個数を指定できる。初期値は1個。同じ項目を複数個追加しても、それぞれの項目名・所要時間・順番を別々に変更できる。

個数は1〜200の整数。空欄・小数・0は追加前にエラーを表示し、編集中の予定を保持する。1日200項目、イベント全体1000項目の上限を超える追加も防ぐ。

選択肢と追加済みの項目は、種類ごとに共通の淡い背景色で表示する。昼休憩は淡い黄、ディスカッションは淡い紫、グループディスカッションは淡いピンク、講演は淡い緑。演者の講演も講演と同じ色とし、種類名の表示も併用する。

追加項目はプルダウンの「基本の項目」「登録演者の講演」から選択する。選んだ候補だけに個数と所要時間を表示し、複数の候補をまとめて追加できる。不要な候補は「外す」で除外できる。種類ごとの淡い色は追加候補と追加後の予定で共通。
