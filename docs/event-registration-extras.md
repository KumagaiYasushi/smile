# イベント登録画面での出欠・昼食入力

2026-11-02の追加要望により、新規登録・イベント編集の同じ画面に出欠フォームと昼食手配フォームを追加した。全3イベント種別で使える。

## 新規登録

1. イベント種別→セミナー名→開催回数を入力する。開催日は日付だけを標準とし、開催方法は日付ごとに選ぶ。外部講師欄で外部講師のあり・なしを選び、ありなら氏名・勤務施設名のリストから選択する。
2. 同じ画面の「研究会講師・サポートの出欠登録」で、名簿から出席・午前のみ・午後のみ・欠席・未登録を選ぶ。複数回は開催日を切り替えて入力する。
3. 「昼食の手配」の「＋ 昼食手配を追加」から、複数選択の対象・対象別オーダー個数・単価・追加費用・お店・連絡先・メニュー・状態・備考を入力する。外部講師も対象に含む。同じ注文で複数対象を選択でき、複数日・店舗は別の手配として追加できる。
4. 最後に「登録する」でイベント・出欠・昼食を一緒に保存する。

出欠は緑（出席）・グレー（欠席）・黒（未登録）で選択内容を表示する。この画面でのラジオ操作は入力中の内容であり、イベント保存前に出欠だけを自動保存しない。
昼食の入力は任意。未入力でイベントだけを作成し、後から追加することもできる。人数・費用の空欄は未定、0円は無料として区別する。

## 登録後

- イベント編集画面に保存済みの出欠と昼食を表示する。変更・昼食の追加後は「変更を保存」でまとめて保存する。
- イベント詳細の「講師・サポートの出欠予定」は引き続き使える。この専用画面のラジオ操作はその場で保存する。
- イベント詳細の「昼食の手配」からも追加・編集・削除できる。
- イベント編集画面で保存済みの昼食を削除すると、確認後に削除対象となり、「変更を保存」で実際に削除する。未保存の新規手配はその場で入力を取り消す。
- 店舗への注文や変更連絡は別途行う。追加時の個数は出席登録と参加者名簿から対象別に設定し、その後は手入力を保持する。反映ボタンで最新の人数を取り込める。

## 失敗・競合時

イベント本体、基本タスクの自動作成、変更した出欠、昼食・打ち合わせの追加・更新・削除、変更履歴を同じデータベーストランザクションで扱う。[基本タスク](standard-tasks.md) は外部講師あり3件／なし1件を登録する。
入力エラー、競合、保存失敗が起きた場合は全体を戻し、一部だけ保存しない。画面の入力は残して理由を表示する。
別操作で出欠・昼食・名簿・開催日が変わった場合も、古い内容で上書きしない。「出欠・昼食を再取得」を押し、編集中の出欠・昼食を破棄する確認後に最新内容へ戻せる。
出欠や昼食を編集していない場合は送信せず、他の画面で追加・変更した記録を保持する。

## API

POST `/api/seminars` と PATCH `/api/seminars/{id}` の任意項目 `registration` に以下を送る。

- `schedule`：現在の開催日を昇順で並べた配列。未定は空配列。
- `attendance`：変更した名簿行の `member_id`、`member_version`、`version`、変更した日付だけの `responses`。未登録の出欠バージョンは0。日程未定のキーは空文字列。
- `lunch`：`action` が `create` の場合は `data`、`update` は `id`・`version`・`data`、`delete` は `id`・`version`。`data` は既存の昼食入力と同じ形式。

ログイン・同一Originを確認し、氏名や操作アカウントを入力から採用しない。出欠・昼食のバージョンとイベント範囲を各専用ストアで確認する。
登録時の昼食も既存の `event_lunch_plans`、出欠も `event_staff` に保存し、専用画面と同じ情報を参照する。

## 検証

単体テストはイベント・2日分の出欠・昼食の同時保存、失敗時の全体ロールバック、編集競合、任意入力と登録後の変更、他イベントの昼食削除拒否を確認する。
API結合テストは全3種別で、新規・編集・競合・CSRF拒否・失敗時のイベント作成取り消し・登録後の追加を確認する。
ブラウザーでは登録画面での出欠・昼食入力、保存503後の入力保持、編集画面での表示と変更、409競合後の全体保持と再取得、専用昼食画面からの変更を確認する。

打ち合わせは登録・編集画面と専用画面で扱う。[打ち合わせ・HOME](meetings-home.md) を参照。`registration.meetings` は任意の変更配列で、他の登録内容と同一トランザクションで保存する。

## 入力画面の開閉（2026-11-03追加）

最初は基本情報だけを開く。外部講師・役割担当・イベント当日の出欠・打ち合わせ・参加費・会場・昼食・懇親会・メモは必要な項目を開いて入力する。「項目へ移動」は対象を開いて移動し、「すべて開く／閉じる」も使用できる。開閉で未保存の入力を消さない。登録・保存ボタンはフォーム末尾へ配置し、入力中は画面に固定表示しない。キャンセルとは間隔を空け、キャンセル時は破棄確認を行う。閉じた項目の入力エラーはその項目を開いて表示する。
開催・打ち合わせ・懇親会・タイムスケジュールの開始時刻は10分単位の時刻入力欄に統一する。ダイアルで選択するボタンは削除した。終了時刻も10分単位とし、開始時刻以降に設定する。保存済みの刻み外の時刻は自動で丸めず、編集時に10分単位へ修正する。

「役割担当」は準備6種類と当日4種類を名簿から複数人で選び、同じイベント登録で保存する。詳細は [イベントの役割担当](event-roles.md)。

## 編集中の画面位置

イベント登録・編集では、入力・項目追加・開閉の際に現在のスクロール位置を保持する。ブラウザーの自動スクロール補正を抑え、スマートフォンの入力欄は16px以上にして入力時の自動拡大を防ぐ。通常のスクロール、項目へ移動、保存時のエラー項目への移動は利用できる。項目へ移動はアニメーションなしですぐ移動する。内容を閉じてページ全体が短くなった場合は、新しいページの末尾までの範囲内で位置を保持する。
