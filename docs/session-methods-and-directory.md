# 各回の開催方法・研究会名簿・再受講料金

2026-11-02の追加要望に基づく変更。全3イベント種別で利用できる。

## 各開催日の開催方法

単回・複数回とも、日程を入力すると日付ごとの3択（現地開催／オンライン／現地開催＋オンライン）が現れる。
日付が決まっている新規イベントでは、各日の選択を必須とする。基本情報の先頭はイベント種別→セミナー名→開催回数の順とし、上部の共通の開催方法欄は置かない。日程未定では開催方法も後から設定する。
既存データの方法は日別設定がない間、従来の共通設定を使う。編集では保存済みの共通設定を各日の初期値に表示する。
一覧は各回で使う開催方法を併記し、詳細・SNS・メールでは日付ごとの開催方法を表示する。全日オンラインなら案内文に内部会場を掲載せず、現地開催を含む場合は会場を掲載する。
日程変更で旧日付の方法は保持し、新日付には共通の方法を使う。変更後にイベント編集から新しい各回の方法を確認する。

## 研究会講師・サポート名簿

上部メニューの「講師・サポート名簿」から氏名・区分を追加・編集できる。利用停止にすると新しい選択候補から外れる。
イベントの研究会講師・研究会サポートメンバーと、出欠予定の同2区分は名簿の氏名を選択する。イベントの外来講師は「あり・なし」と氏名・勤務施設名の専用リストを使う。[外来講師リスト](external-lecturers.md) を参照。個別の出欠予定画面では従来の氏名入力も保持する。
名簿はログインアカウントとは別で、氏名を登録してもアカウント・招待・外部連絡は作成しない。
名簿の編集後はイベント入力欄の「名簿を再取得」で選択肢を更新できる。

利用者が指定した以下の氏名を、各データベースの初回に一度だけ登録する。

イベントの氏名は選択時の記録として保持する。名簿を変更しても登録済みイベント・出欠予定の氏名を一括変更しない。
従来の氏名が名簿にない場合も「保存済み」として保持し、選択し直すまで消さない。
APIは GET/POST `/api/society-members`、PATCH `/api/society-members/{id}`。運営メンバーのログイン、書き込みの同一Origin、編集バージョンを確認する。変更履歴には操作アカウント・区分・利用状態・バージョンを記録し、氏名を複製しない。

## 参加費

複数回では職種別に「複数回合計金額」と「単回金額（再受講用）」を別々に入力する。
従来の参加費は合計金額欄へ保持する。再受講金額は空欄（未設定）が初期値で、0円は無料と区別する。
単回イベントは従来の参加費欄を使う。合計金額から単回金額を自動計算しない。
詳細・SNS・メールで両方の料金を表示する。入金時の金額は実際に確認した額を入力し、発行済み領収書の金額は料金変更で変わらない。
参加者ごとの受講回の選択や自動課金は今回の対象外。

## 新規登録ボタン

入力不備でブラウザーが送信を止め、画面下では理由が分からない場合があった。未入力・不正値を日本語で表示し、対象欄へ移動するようにした。
参加費の100円刻み・会場費の1,000円刻みの制約を外し、円単位の整数を登録できる。
日程未定のイベントはタスクを自動生成せず保存し、日程確定後にテンプレートを適用する。
複数日でタスクを自動生成する場合は、期限の基準日を選択する。未選択ならその項目を案内する。
保存失敗時は入力とエラーを保持して再保存できる。ログイン期限切れはログイン画面へ誘導する。

## 保存・検証

`seminars.session_delivery_methods`（日付→開催方法）と `repeat_fees`（職種→再受講金額）を追加し、既存ID・開催日・更新日時・参加者を保持する。
単体テストは名簿初期化の一回性・変更保持・不正値・同時編集・監査失敗のロールバック、日別設定・料金・旧日付の保持・案内文・領収書の互換性を確認する。
API結合テストは名簿の認証・CSRF・編集競合と、全種別での日別設定・再受講金額の保存を確認する。
ブラウザーでは3画面幅で、名簿の追加と選択、2日で異なる開催方法、1円刻みの金額、未入力案内、保存503後の再保存、日程未定の登録を操作する。
