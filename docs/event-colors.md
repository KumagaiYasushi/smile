# イベント種別の共通配色

`types/event-colors.ts` に共通配色を定義する。ベーシックコースは緑、講演会は青、セミナーは紫、その他はグレー。イベント一覧のカード、ダッシュボードのタスクカード、HOMEの日程行で同じ背景色と種別名を使用する。イベント一覧の見出しは対応する濃色と白文字。期限超過・重要・担当などの状態バッジは別に表示する。

Googleカレンダーへの予定データにも対応するイベント色（緑10・青9・紫3・グレー8）を指定する。打ち合わせ・懇親会は親イベントの種別色。Googleの配色定義を使うため色味はアプリと完全一致しない。同期済みの予定は、アプリで保存し直すか「Googleカレンダー連携」の全件同期で反映できる。実カレンダーの変更は接続後のみ。

`scripts/check-timetable.mjs` でPC・スマートフォン幅の共通背景色、項目選択後の即時追加、指定個数、順序・時間編集、ドラッグ移動、保存後の保持を確認する。
