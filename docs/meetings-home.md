# 打ち合わせ・HOME・外来講師の金額設定

2026-11-02の追加要望。イベント当日の出欠フォームは利用者の回答により保持する。外来講師欄の研究会講師・サポートの選択欄だけを削除し、過去に登録した主担当者・サポートの記録は保持する。

## 打ち合わせ

新規イベント登録・編集画面の「打ち合わせ」で複数件を追加できる。登録後はイベント詳細の「打ち合わせ」からも追加・編集・削除できる。

各回に打ち合わせ名、日付、任意の開始時刻（日本時間）、実開催・オンライン・その他を登録する。日付が未定の場合も保存できる。時刻だけの登録はできない。
研究会講師・研究会講師サポートメンバーの名簿で、出席・午前のみ・午後のみ・欠席・未登録を各回別に登録する。出席と半日出席は緑、欠席はグレー、未登録は黒で表示する。
イベント当日の出欠や、他の打ち合わせへ回答をコピーしない。打ち合わせの日付・時刻を画面で変更すると、その回の出欠を未登録に戻す。開催方法だけの変更では出欠を保持する。

新規登録ではイベント・出欠・昼食・打ち合わせをまとめて保存する。登録後の専用画面は「打ち合わせを保存」で変更をまとめて保存する。保存前の削除は確認後に削除対象となり、保存で確定する。
保存エラー・他操作との競合時は全体を取り消し、入力内容を保持する。「打ち合わせを再取得」は未保存の変更を破棄する確認後に最新値へ戻す。

名簿の改名・利用停止後も保存済みの氏名・区分を保持する。名簿の更新後は再取得してから編集する。新しく追加された有効メンバーは未登録の候補として表示する。
各イベント100件まで。変更履歴には操作アカウント、日時、方法、出欠IDと回答、版を記録し、氏名や自由記載を複製しない。イベント削除時は関連する打ち合わせと履歴も削除する。

## HOME

上部の「HOME」を開く。既存のイベント一覧は「イベント一覧」から利用できる。
イベント開催日と打ち合わせを1日程1行で、日付・時刻の昇順に表示する。未定は末尾。各行に親イベント名、予定名、日程、種別を表示し、打ち合わせの行はそのイベントの打ち合わせ編集画面へ移動する。
「すべて・ベーシックコース・講演会・セミナー・打ち合わせ・その他」のボタンで絞り込む。「打ち合わせ」は親イベントの種別を問わず打ち合わせだけを表示する。各イベント種別ボタンは開催日だけを表示する。
スマートフォンでは各行の内容を縦に並べ、横スクロールを必要としない。
「その他」は新規イベントの種別としても登録できる。既存3種別のイベントはそのまま保持する。停止中のタスクテンプレート管理は従来の3種別のみを対象とする。

## 外来講師の金額

登録画面の「外来講師」で「あり」を選ぶと、お車代・謝礼を円単位の整数で設定できる。空欄は未定、0は0円。イベントごとに保存し、名簿の標準金額にはしない。
「なし」に変えても設定額を保持する。イベント詳細で確認できる。金額から振込・送金・領収書発行は行わず、SNS・メールの参加案内へ金額を掲載しない。

## 保存・API

- `event_meetings` と `event_meeting_history` にイベントIDを持つ記録を保存する。既存イベントの打ち合わせは空から始まる。
- GET `/api/seminars/{id}/meetings` は打ち合わせ一覧と研究会名簿を返す。POSTは `changes` 配列で `create` / `update` / `delete` を一括適用する。更新・削除は `id` と `version`、追加・更新は `data` が必要。
- `data` は `title` / `date` / `time` / `method` / `attendees`。出欠は `member_id` / `member_version` / `response` を送り、氏名・区分はサーバー側で名簿から確定する。
- 新規登録・編集の `registration` は任意の `meetings` 配列として同じ変更形式を受け付ける。
- GET `/api/home` は認証済み運営メンバー向けの日程一覧を返す。
- `seminars.external_payment` は `{travel:null,honorarium:null}` を既存行の初期値とし、JSONで金額を保存する。変更時は両方の項目を送る。
- 書き込みはログイン・同一Originを確認する。更新競合は409、別イベントの打ち合わせIDは404、不正日時・金額・名簿・重複ID等は400。返却値をキャッシュしない。

「その他」の追加では既存SQLiteのイベント種別制約を拡張する。元の列・ID・更新日時・自動採番上限・インデックス・トリガー・子テーブルを保持して切り替え、失敗時は元に戻す。外部キーの設定も元に戻す。

単体テストで独立した出欠・版・イベント範囲・監査失敗・一括保存の取り消し、HOMEの順序、金額検証と旧DB移行を確認する。APIとPC・スマートフォンでは、新規登録から登録後編集、HOMEの絞り込み、日程変更後の出欠リセット、金額設定、削除まで確認する。
