# タスクテンプレート（生成停止中）

2026-11-02の利用者指定により、テンプレートからのタスク生成機能をいったん削除した。

- 新規イベント登録の自動生成チェック欄・期限の基準日欄を削除する。
- イベント作成時にテンプレートが登録済みでも、タスクを生成しない。日程未定・複数日でも、タスク用の基準日を選ばず登録できる。
- タスク画面の生成プレビュー・確認付き追加を削除する。
- 必要なタスクは「タスク・期限管理」の「＋ タスクを追加」から個別に登録する。

既存のタスク・期限・進捗・担当者・履歴は保持する。保存済みテンプレートの管理画面では、名称・説明・相対日数・重要設定・有効設定を保管・編集できる。テンプレートの編集で既存タスクを変更しない。
過去の生成記録も保持し、[開催日・期限変更](reschedule.md) で既存の期限を確認・変更できる。

## API

生成API POST `/api/seminars/{id}/tasks/template-preview` と `/apply-templates` は認証・同一Originを確認したうえで410を返し、生成しない。
旧クライアントのイベント登録が `generate_tasks: true` や `task_base_date` を送っても、タスクを生成しない。既存のイベント入力・出欠・昼食の保存は引き続き利用できる。

テンプレート管理の GET/POST `/api/task-templates`、PATCH `/api/task-templates/{id}` は保持する。編集時はバージョンを確認する。
停止に伴う既存データの削除や書き換えは行わない。過去の生成・日程変更の互換性を検証するため、生成ストアの内部処理とテスト用の旧データ作成処理は残す。アプリのイベント作成や生成APIから呼び出さない。

## 検証

単体テストは既存記録の互換性と日程変更を確認する。API結合テストは全3種別・日程未定・単回・複数日のイベント作成で生成されないこと、旧生成フラグでも生成されないこと、生成APIの410・認証・CSRF、既存タスクの保持を確認する。
ブラウザーではPC・スマートフォンで生成操作が表示されないことと、個別タスクの追加・編集、過去の生成タスクの保持・日程変更を確認する。
