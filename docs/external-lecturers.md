# 外来講師リスト

イベント新規登録・編集の「講師・スタッフ」で外来講師を「あり・なし」から選ぶ。「あり」の場合は、氏名と勤務施設名の組をリストから選ぶ。
上部メニューの「外来講師リスト」で氏名・勤務施設名を追加・編集できる。利用停止にした人は新しい選択候補から外れる。イベント入力中は別タブで管理画面を開き、戻ってリストを再取得できる。

利用者指定の初期データを各データベースに一度だけ登録する。

| 氏名 | 勤務施設名 |
| --- | --- |
| 長谷剛志 | 能登総合病院 |
| 橋本二郎 | 東京大学生物学講座 |

改名・施設変更・利用停止は再起動後も保持し、初期値に戻さない。過去のイベントは選択時の氏名・勤務施設名を保持し、名簿の編集で一括変更しない。別の人に切り替えると新しい選択内容を記録する。「なし」に切り替えても過去に選択した情報は保持し、表示・昼食人数の初期値から除外する。
旧イベントの直接入力された外来講師名も、選択し直すまで保存済みとして保持する。既存イベントの更新日時や他の記録は移行時に変更しない。

APIは GET/POST `/api/external-lecturers`、PATCH `/api/external-lecturers/{id}`。書き込みはログイン済み運営メンバー、同一Origin、編集バージョンを確認する。氏名・勤務施設名の同じ組は重複登録しない。イベントの新しい選択はサーバー側で有効な名簿IDから確定する。
名簿の変更履歴には操作アカウント・利用状態・バージョンを記録し、氏名・施設名を複製しない。保存と履歴は一括で戻せるよう同じトランザクションで扱う。

単体テスト・API結合テストで初期値、編集保持、重複・入力検証、競合、認証・CSRF、監査失敗の取り消し、イベント記録保持を確認する。ブラウザーではPC・スマートフォンで名簿の追加・編集とイベントからの選択を確認する。
