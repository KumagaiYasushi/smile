# イベント一覧の予定表示

イベントの各開催日、登録済みの打ち合わせ、開催する懇親会の各回を独立した予定として日付・開始時刻の昇順に表示する。日付未定は末尾。日程調整中の候補日時と「開催しない／未定」の懇親会は含めない。複数回イベントは開催日ごとに第○回を表示する。共通配色は親イベントの種別に従う。

一覧上部のアイコン（詳細／行）で表示を切り替える。初期は詳細カード、行表示は「日付・イベント名・会場」の3列。各行の間に8pxの余白を取り、角丸と枠線で予定を独立させる。選択した形式をブラウザに記憶する。保存が制限されているブラウザでも、その画面内の切り替えは利用できる。種別の絞り込みと「イベント／打ち合わせ／懇親会」の絞り込みを組み合わせられる。

イベント名はイベント詳細へ、打ち合わせ名は親イベントの打ち合わせページへ移動する。懇親会名は親イベントの詳細を開く。行表示のお店URLはリンクとして開ける。打ち合わせは専用の会場情報を持たないため、オンラインの場合はオンライン、実開催は会場未設定と表示し、イベント会場を推測して転記しない。

`GET /api/event-list` は運営メンバーの認証が必要で、同一のDB読み取りトランザクションからイベントと統合した予定を返す。行表示には個々の出欠を掲載しない。API失敗時は空一覧の案内と区別してエラーを表示する。

`tests/event-list.test.mjs` で予定の分離・順序・開催有無・日別オンライン・旧形式懇親会・キーの一意性を確認。`scripts/check-event-list-views.mjs` でPC・390px・320px幅の独立カード、3列表示、切り替え保持、絞り込み、リンク、認証・エラー表示を検証する。
