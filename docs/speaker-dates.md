# 開催日ごとの演者登録

イベント新規登録・編集の「演者登録（複数名登録可）」では、複数回開催を選ぶと各演者に「登壇日」を表示する。基本情報に入力した開催日から選択する。1日ごとに複数名を登録でき、同じ方も別の日には再登録してテーマを変えられる。各外部講師のお車代・謝礼は登壇登録ごとに設定し、イベント全体の費用へ合計する。新規の外部講師は従来どおり名簿へ保存し、別の日でも同じ名簿項目を再利用する。

既存の演者や日程未定の演者は「全開催日共通」を引き継ぐ。単回開催は従来と同じ入力方法。共通の演者と同じ方を特定の日にも重複登録すること、同じ日に同じ方を重複登録することは拒否する。日別登録は同じ人でも個別のテーマと支払いを保持する。

タイムスケジュールは対象の日の演者と共通の演者だけを講演候補に表示する。日別の講演キーに開催日を含めてテーマを区別し、別の日の演者の新規割当はサーバーでも拒否する。既存の保存済み講演はその日で記録を保持する。

イベント概要、開催要項、メールの演者・テーマ欄にも登壇日を表示する。メールの依頼文は従来どおりタスク内の内容を優先する。

開催日の変更・削除で演者を自動削除しない。保存済みの旧日程は記録を残して確認表示し、演者の登壇日から再割当できる。新規登録中に日付を変更した場合も、登壇日を改めて選択する。登録済みの開催日以外に新たな登壇登録はできない。
