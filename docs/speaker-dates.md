# 開催日ごとの演者登録

イベント新規登録・編集の「演者登録（複数名登録可）」では、複数回開催では基本情報に入力した開催日ごとに登録欄を表示する。各日の「この日に演者を追加」で、その日に演者を直接追加する。各欄には登録人数を表示する。「登壇日」の選択を変更すると別の日の欄へ移動できる。1日ごとに複数名を登録でき、同じ方も別の日には再登録してテーマを変えられる。各外部講師のお車代・謝礼は登壇登録ごとに設定し、イベント全体の費用へ合計する。新規の外部講師は従来どおり名簿へ保存し、別の日でも同じ名簿項目を再利用する。

複数回開催の「全開催日共通・日程未定」の新規登録欄と、共通への変更選択肢は削除した。開催日が未入力の場合は基本情報での入力を案内する。旧データの登壇日未設定の演者だけは内容を残して表示し、開催日を指定して振り分けられる。単回開催は従来と同じ入力方法。共通の演者と同じ方を特定の日にも重複登録すること、同じ日に同じ方を重複登録することは拒否する。日別登録は同じ人でも個別のテーマと支払いを保持する。

タイムスケジュールは対象の日の演者と共通の演者だけを講演候補に表示する。日別の講演キーに開催日を含めてテーマを区別し、別の日の演者の新規割当はサーバーでも拒否する。既存の保存済み講演はその日で記録を保持する。

イベント概要、開催要項、メールの演者・テーマ欄にも登壇日を表示する。メールの依頼文は従来どおりタスク内の内容を優先する。

開催日の変更・削除で演者を自動削除しない。保存済みの旧日程は記録を残して確認表示し、演者の登壇日から再割当できる。新規登録中に日付を変更した場合も、登壇日を改めて選択する。登録済みの開催日以外に新たな登壇登録はできない。

## 入力画面

演者は氏名・区分・テーマのコンパクトな一覧で表示し、「編集」で詳細を開く。一度に編集する演者は1名とし、新しい演者を追加するとその入力欄が開く。「入力を閉じる」は入力値を保持して一覧へ戻す。名簿選択はPCでは2列に配置し、スマートフォンでは縦に並べる。保存時に必須項目が不足している場合は該当する入力欄を開いてエラーを表示する。
