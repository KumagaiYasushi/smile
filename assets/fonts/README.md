# Japanese font for event outline PDFs

`NotoSansJP-Regular.ttf` is a static regular-weight (400) instance of Noto Sans JP, derived from the Google Fonts variable font using `fontTools.varLib.instancer.instantiateVariableFont` with `updateFontNames=True`.

Source: https://raw.githubusercontent.com/google/fonts/main/ofl/notosansjp/NotoSansJP%5Bwght%5D.ttf
Upstream project: https://github.com/google/fonts/tree/main/ofl/notosansjp

The accompanying `OFL.txt` is the SIL Open Font License. The font and its copyright are retained under that license. The static font is bundled so production PDF exports can embed readable Japanese glyphs without external font requests or a font conversion tool at runtime.
